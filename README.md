Telecom AI Brand Intelligence System

An AI-powered telecom complaint analysis platform built using BERT Transformers, RAG architecture, FAISS vector search, and Streamlit.
The system automatically analyzes telecom customer feedback, detects sentiment, identifies service categories, retrieves relevant telecom policies,and generates AI-based responses.

Features

User & Admin Authentication
BERT-based Sentiment Analysis
Telecom Service Category Detection
RAG-based Document Retrieval
AI-generated Customer Responses
SQLite Database Integration
Interactive Admin Analytics Dashboard
